## 2. アセット運用方針
* **実写写真への差し替え:** オーナー様より実際の店舗・料理・スタッフ等の高解像度写真をご支給いただいた場合は、同名ファイルで上書き、または個別タグ差し替えが可能です。
* **クリーン運用:** 本番公開用クリーン版（`manoamano/`）にも `npm run sync` で同一画像群が同期されます。
