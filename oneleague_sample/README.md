# ONE LEAGUE 2027

地域アマチュアフットサルリーグ「ONE LEAGUE 2027」の公式運営Webサイト / LPです。
本リポジトリでは `oneleague_sample/` を Single Source of Truth（編集元）とし、`npm run sync -- oneleague` により本番クリーン版 `oneleague/` へ同期する運用構成をとっています。

## 確定情報

- ONE LEAGUE 2027 / ~enjoy Futsal league~
- リーグ期間：2027年2月〜11月
- 12月：王者決定戦・表彰式・閉会式
- 8チーム / 年間56試合
- メインスポンサー：いちものがたり（フッターに控えめに掲載）

## 起動方法

依存パッケージ不要のHTML・CSS・JavaScript（Vanilla ESM）です。
`index.html` の直接ダブルクリックではブラウザのセキュリティ制限によりJSON取得ができないため、ローカルHTTPサーバー経由で閲覧してください。

### 単体ローカル起動
`oneleague` または `oneleague_sample` ディレクトリで以下を実行し、表示されたローカルURL（`http://127.0.0.1:4193`）を開いてください（Python 3が必要）。

```bash
cd oneleague
python3 -m http.server 4193 --bind 127.0.0.1
```

### 制作ポータル・Cloudflare共有起動
親ディレクトリ（LP作成ルート）から以下を実行することで、外部確認用トンネルURLを発行して閲覧できます。

```bash
npm run share
```

## データ更新・同期

編集・更新は必ず `oneleague_sample/` で行い、完了後に同期コマンドを実行してください。

```bash
# 編集後に同期
npm run sync -- oneleague
```

### 主な管理ファイル
- `data/league-data.json`：順位・日程・結果・チーム紹介の共通データ。
  - `teams`：チームのID、名称、略称、エンブレム文字、色、紹介文。
  - `matches`：対戦情報。`home` / `away` はチームID。
  - `status: "scheduled"`：試合予定。スコアは `null`。
  - `status: "finished"`：試合終了。両スコアに0以上の整数を記入すると順位を自動計算。
  - `date` は `YYYY-MM-DD`、`time` は `HH:MM`。
  - `points`：勝利・引き分け・敗戦の勝点。
  - 同勝点は得失点差、総得点で比較。同一成績は同順位として表示します。
  - `contact.lineUrl`：正式な `https://lin.ee/…` または `https://line.me/…` を設定すると公式LINEボタンを表示。
- `index.html`：リーグ概要、ルール、FAQ、コピーライティングの管理。
- `styles.css`：レスポンシブデザイン・タイポグラフィの管理。

現在は8つの架空チーム、終了12試合、予定4試合のデモです。年間56試合の正式な組み合わせを作成したものではありません。デモの日付は実際の大会日程を表しません。

## 正式公開に向けて必要な情報

実チーム名・ロゴ・紹介文、会場とアクセス、参加費、競技時間・順位規定・審判体制・用具、荒天時の判断と連絡方法、運営窓口、次年度参加案内の受付方法。これらは未確定としてページ上に明記しています。フォームや待機リストの登録処理はありません。

実データへの切り替え時はJSONの `mode` を `official` に変更し、HTMLのデモに関する説明（チーム紹介の注記・日程注記・順位規定・FAQ）も正式内容へ更新してください。更新後は `npm run sync -- oneleague` で本番版へ反映します。

## 検証

親ディレクトリ（LP作成ルート）から以下を実行します。

```bash
# リーグ集計・フィルター・節終了判定の単体テスト
npm run test:league

# または直接実行
node --test oneleague/tests/league.test.mjs
```

テスト内容：集計整合性、未実施・不正スコアの除外、同率順位、チーム・節フィルター、節終了判定表記（全試合終了・部分終了・開幕前・未消化）。

ブラウザ確認：PC 1280px、スマホ375px / 414pxで横はみ出しなし。順位詳細、日程のチーム絞り込み、結果の節切り替え、モバイルメニュー、チーム紹介ダイアログを確認。
